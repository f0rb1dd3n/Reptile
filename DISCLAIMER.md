# Disclaimer and Acceptable Use Notice

## Purpose

Reptile is published solely for legitimate security research, education,
defensive testing, and analysis in controlled environments. It is intended to
help security professionals, researchers, and students understand Linux kernel
rootkit techniques so they can study, detect, and defend against them.

## Danger and potential impact

This repository contains source code for a Linux kernel rootkit. Its
capabilities include privilege escalation, stealth and concealment,
persistence, remote command execution, network connection hiding, and file
content tampering. If installed or used improperly, it can compromise the
security, privacy, integrity, and availability of a system. It may also cause
kernel instability, system crashes, data loss, detection evasion, or
unauthorized access and control.

isolated lab or disposable virtual machine with no sensitive data and no
unnecessary access to other networks.
